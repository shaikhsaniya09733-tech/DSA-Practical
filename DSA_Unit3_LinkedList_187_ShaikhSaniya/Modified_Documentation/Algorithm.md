# Algorithm

## Canteen Order Processing Using Linked List

1. Start the program.
2. Initialize the head pointers of SLL, DLL, and CLL.
3. Display the main menu.
4. Select SLL, DLL, CLL, or Exit.
5. Display the menu for the selected linked list.
6. Select an operation:
   - Insert an order at the beginning, end, or specified position.
   - Delete an order by Order ID or specified position.
   - Search for a specific food order.
   - Display the linked list.
   - Perform forward or backward traversal, where applicable.
7. Perform the selected operation.
8. Display the result.
9. Return to the main menu of the selected linked list.
10. Repeat until the user returns to the main menu.
11. Repeat the main menu until Exit is selected.
12. Release dynamically allocated memory.
13. Stop the program.
