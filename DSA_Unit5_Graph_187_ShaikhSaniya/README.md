# DSA Unit V – Graphs


## Topic

**Graph Operations Using Adjacency Matrix and Adjacency List**

## Problem Statement

Develop a menu-driven C++ program for graph operations, including vertex and edge insertion, deletion, graph display, BFS, and DFS. Provide options to display the graph as an adjacency matrix or adjacency list, update the graph, and show the result after each operation.

## Objectives

1. To understand graph representation using an adjacency matrix and adjacency list.
2. To perform vertex and edge insertion and deletion.
3. To implement Breadth-First Search (BFS) and Depth-First Search (DFS).
4. To display and update graph information.
5. To handle disconnected vertices and unavailable paths.
