# Algorithm – Graph Operations

1. Start the program.
2. Initialize an empty graph.
3. Display the menu of graph operations.
4. Accept the user's choice.
5. Perform the selected operation:

   * **Insert Vertex:** Add a new vertex to the graph.
   * **Insert Edge:** Connect two vertices with an edge.
   * **Delete Vertex:** Remove a vertex and its connected edges.
   * **Delete Edge:** Remove the edge between two vertices.
   * **Display Graph:** Show the graph using an adjacency matrix or adjacency list.
   * **BFS:** Traverse the graph using Breadth-First Search.
   * **DFS:** Traverse the graph using Depth-First Search.
   * **Update Graph:** Modify the graph and display the updated result.
6. Display the result of the selected operation.
7. Repeat the menu until the user chooses Exit.
8. Stop the program.
