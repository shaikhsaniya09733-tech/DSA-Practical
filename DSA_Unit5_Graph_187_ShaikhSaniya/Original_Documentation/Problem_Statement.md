# Problem Statement – Graph Operations

## Title

Graph Operations Using Adjacency Matrix and Adjacency List

## Problem Statement

Develop a menu-driven C++ program for graph operations, including vertex and edge insertion, deletion, graph display, Breadth-First Search (BFS), and Depth-First Search (DFS). The program should provide options to display the graph using an adjacency matrix or adjacency list, update the graph, and display the result after each operation.

## Objective

To implement basic graph operations in C++ and understand graph representation and traversal using an adjacency matrix, adjacency list, BFS, and DFS.

## Expected Outcome

The program should allow users to insert and delete vertices and edges, display the graph in both representations, perform BFS and DFS traversal, and show updated graph results after each operation.
