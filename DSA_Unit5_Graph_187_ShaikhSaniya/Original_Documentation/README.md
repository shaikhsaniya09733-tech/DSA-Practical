# Original Documentation – Graph Operations

## Problem Statement

Develop a menu-driven C++ program for graph operations, including vertex and edge insertion, deletion, graph display, BFS, and DFS. Provide options to display the graph as an adjacency matrix or adjacency list, update the graph, and show the result after each operation.

## Description

This program performs basic graph operations using C++. It supports vertex and edge insertion, deletion, graph display using an adjacency matrix or adjacency list, and graph traversal using BFS and DFS.
