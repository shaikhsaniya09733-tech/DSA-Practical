# Problem Statement – Modified Graph Operations

## Title

Enhanced Graph Operations Using BFS and DFS

## Problem Statement

Modify the original menu-driven C++ graph program to accept additional vertices and edges and display the updated graph. Compare BFS and DFS traversal results before and after graph updates. The program should also identify disconnected vertices and display an appropriate message when a path between two vertices is unavailable.

## Objectives

1. To add vertices and edges dynamically and display the updated graph.
2. To compare BFS and DFS traversal results before and after graph modifications.
3. To detect disconnected vertices and handle unavailable paths.
4. To improve graph traversal and connectivity checking.

## Expected Outcome

The modified program should support graph updates, show before-and-after traversal results, and display clear messages for disconnected vertices or unavailable paths.
