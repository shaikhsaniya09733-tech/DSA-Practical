# Algorithm – Modified Graph Operations

1. Start the program.
2. Initialize an empty graph.
3. Display the menu of graph operations.
4. Accept the user's choice.
5. Perform the selected operation:

   * Insert additional vertices.
   * Insert or delete edges.
   * Delete vertices.
   * Display the adjacency matrix or adjacency list.
6. Before updating the graph, perform BFS and DFS and record their traversal results.
7. Update the graph by inserting or deleting vertices or edges.
8. Display the updated graph.
9. Perform BFS and DFS again and compare the results before and after the update.
10. Check connectivity between the selected vertices.
11. If a path is unavailable, display an appropriate message.
12. Repeat the menu until the user selects Exit.
13. Stop the program.
