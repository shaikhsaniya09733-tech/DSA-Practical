# Algorithm: AVL Imbalance Detection

1. Start the program.
2. Create an empty AVL tree.
3. Enter the values to be inserted into the tree.
4. Insert each value using Binary Search Tree insertion rules.
5. Update the height of each node.
6. Calculate the balance factor of each node.

   Balance Factor = Height of Left Subtree - Height of Right Subtree

7. Check for imbalance:
   - LL Case: Perform Right Rotation.
   - RR Case: Perform Left Rotation.
   - LR Case: Perform Left Rotation, then Right Rotation.
   - RL Case: Perform Right Rotation, then Left Rotation.
8. Display the balanced AVL tree.
9. Stop the program.
