# Problem Statement

## AVL Imbalance Detection with Enhanced Features

Write a C++ program to detect LL, RR, LR, and RL imbalances during AVL tree insertion, identify the rotation required, and display the balanced tree.

## Modifications

1. Display the first unbalanced ancestor and its balance factor.
2. Record the rotation type and affected node values.
3. Test all four rotation cases and verify the final AVL tree balance conditions.
